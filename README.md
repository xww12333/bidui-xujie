## 简要概述

本项目从一个追问出发：**差异存在为什么存在？**  
追问下来会发现：所谓「差异存在」，并不是另立的一条公理，而是**不可约比对操作持续续接作用**这一活动本身所呈现的**面向**——比对只与近邻作用，结果立刻成为下一步的作用对象；活动在，差异就在。

对这条活动做**面向的代数分析**：面向如何自交互、如何轮替、乘积如何闭合。数完面向，恰好三个；把这些硬约束记下来，记录语言就是**四元数 ℍ**。

**重点不是先学会 ℍ，而是学会回到活动里验记录。** 代数是记录，不是事先选好的舞台；公式、boxed、印数若还原不到比对续接的某一步，就不算忠实记录。

再看活动的**近邻作用**如何在续接里铺开：三个面向长成三根锁死的管，比对沿管延续叫做**传态**；事件与螺旋是同一句话的两读。于是得到一张**传态网络**——一边用 **ℍ 代数**记账，一边用**三管螺旋、正交、协变的动态几何**描述同一过程；两者共同刻画这张网，不是两套无关的故事。

其后出现的谱、耦合、时空、G 与 ℏ 等，**不是外贴参数表**。它们来自对这张传态网络上**局域事件**（交汇、翻转、绕面、堆积、截面……）的结构分析：座位定在哪一层、哪一口，数就从那里读出。实验能量切口实质上只有一刀（`mτ`）；其余大量关系是网络内的无量纲结构。认知篇则表明：同一套生成条件还可读另一张图，但**不与物理网共享顶点**。卷20 把日常现象收进同一套读法（索引）；卷21–22 在已有表示上闭出纠缠（Bell／CHSH）与测量（S–M 交汇、Born、坍缩记账）；卷23 把事件计数 $n_k=4,13,30$ 逐步统计闭成独立一卷；卷24 把衰变宽度按四档对照实验，并钉死衰变 $\neq$ 卷四质量隧穿；卷25 加固类型账手征与 $f_\pi$、 $g_A$ 的活动链（III⁺；表数字冻结）。

一句话：**追问差异 → 看见比对续接的面向 → ℍ 记录三面向闭合 → 近邻传态长成代数与三管几何共写的网络 → 一切可钉死的数，都是这张网上局域事件的分析结果。**

## 先看这六点（关键点）

1. **活动优先，记录忠实**（卷1 总纲，后文不变）  
   读任何一章，先问：这一步在比对续接活动里**实际在发生什么**？  
   符号只是忠实记录；**不能**因为先看见了 ℍ、SU(3)、Einstein 方程，就倒回去当前提。  
   检验标准：能否从记录**还原**到近邻比对序列，且序列**打不打结**。

2. **方向不可倒**  
   不是先选 ℍ / 标准模型 / Einstein，再给差异找舞台。  
   比对近邻续接自己提出要求 → 记成代数 → 记录名才叫 ℍ。

3. **差异存在不是公理表第一条**  
   它不能被证明、也不能被否定；启用证明已经在用它。  
   本项目的「证明」= 沿规划路径重演比对，看**打不打结**（断在哪）。

4. **实验能量切口只有一刀：`mτ`**  
   其余大量无量纲结构（`nk`、`S1`、`q`、`40`、`3/13`、堆积…）从座位长出，不是一堆自由拟合旋钮。

5. **两口不并、座位分明**（全文最高频禁令）  
   尤其卷16：**几何锁 G**（分母 `16π cκ`）与 **事件锁 ℏ**（每边 `ln 2`）交叉在同一根 `a_UV`，**不许并成一个分母**。  
   把事件比 ~1.058 说成「G 算错」，或把对照 `0.99961` 收进钉死，都断。

6. **三个「三」不可互换**  
   三面向（卷1）$\neq$ 空间三维（卷14）$\neq$ 三代/三色（后文各有座位）。并成一句就会读歪整条链。

## 重点关节点（比目录更重要）

### A. 卷1：为何恰好三个面向

续接要求记下之后数面向：1 个方向消失；2 个乘积关不住；**3 个乘法表闭合 = ℍ**；≥4 无处转向。  
停在 ℍ。管、粒子、时空下一卷才开始。

**本卷读法：** 代数符号是记录，不是前提；每一步都要能还原到比对续接活动本身，检验记录是否忠实。先活动、后符号；先问「断在哪」，再认 boxed。

### B. 卷2–3：网络与账本

三个面向 → 三管锁死 → 传态（比对沿管延续）→ 绕最小面 `H_P=−1`。  
同一笔传态分三层账 → 规范群是账本自同构，不是外加装饰。

**卷3补：** 有人质疑「正传／反传都是左乘、都线性，故不能拆单态」。补卷用活动序列钉死：$`\mathbb{R}`$-线性（承认）$\neq$ 双态坐标下的 $`\mathbb{C}`$-线性；反传展开 $e_2^{-1}(z_1+z_2e_2)=\bar z_2-\bar z_1 e_2$，坐标映射反线性 ⇒ 拆单态。与卷3 第三章同结论。

**卷2–4 读法（与卷1 同纲）：** 各卷「读法与指引」开头有 **记录与活动**——符号、账本、 $n_k$/`q` 都要能还原到传态续接或局域事件本身，检验是否忠实；禁止先套几何圆柱、标准模型表或实验室编号再往回填。
