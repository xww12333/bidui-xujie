# 《比对续接——差异传态网络》

本仓库是一套**从生成条件往前推**的理论文稿，不是先选定标准模型或广义相对论再往回填数。  
正文：`卷1.md` … `卷17.md`。数字核验在 `scripts/`，只负责复算已锁印数，**不能代替推导**。

纪律：不改变已锁数字与逻辑；两口不并；座位分明；不假装做了的；每断一条都要说清「断在哪」。

## 项目基于什么（先读这段）

### 一句话

**差异存在**（不可约比对的持续近邻续接）自己提出结构要求 → 记成代数 → 恰好三个面向闭合（记录名 ℍ）→ 长出三管与传态网络 → 在同一张网上读出粒子谱、耦合、时空、G 与 ℏ → 最后用同一套生成条件谈认知（另一张图，不共享顶点）。

代数、群名、常数都是**记录**，不是前提。不是「先选了四元数 / SU(3)×SU(2)×U(1) / Einstein，再给差异找舞台」。

### 「证明」在本项目里指什么

不是站在差异外面用公理表判决。  
选定一条规划路径，一步步近邻比对，看序列打不打结：**通过则站住，打结则断在那一章**。  
「差异存在」本身不能被证明或否定——启用证明已经在用它。

### 数字从哪来（避免「只见印数不见路」）

多数可观测量不是外拟合旋钮，而是沿上表座位长出来的。一条常见脊梁：

1. **卷4** 交汇鞍点给出 `S1`，再 `q = e^(−S1)`。  
2. **卷5** 唯一实验能量切口 `mτ` → `m0 = mτ/q⁴`；取向和 `40 = 1+3+9+27` 只进 `vH = 40 m0`，不进轻子指数。  
3. **卷6–7** 夸克不走轻子同一口井；代隙三刀与绝对谱用 `vH` 与四条比。  
4. **卷12** 用已锁 `S1` 走三刀得到 `1/α(0)`；`sin²θW = 3/13`（`13=1+3+9`，**没有** `Nw=2`）。  
5. **卷16** 无零因子 ⇒ 层间比 40 ⇒ `N_oct=12` ⇒ `a_UV = L_IR/40^12`；**几何**分母 `16π cκ` 锁 G；**事件**每边 `ln 2` 锁 ℏ——交叉在同一根 `a_UV`，**不许并成一个分母**。

实验对照（如 `1/α`、电弱质量）用来诚实对照，**不回改**已锁公式。  
`ℏ` 的 SI 打印数是单位字典循环，**不是**本框架的合法预言靶。

### 卷16：`G/Gobs` 三条路径（已脚本复算）

公式相同：`G = a_UV² / (16π cκ)`。差别只在**输入取位**。

| 路径 | 输入 | 算出 `G/Gobs` | vs 1 | 地位 |
|:---|:---|:---:|:---:|:---|
| **钉死（几何，未圆整）** | `m0=6228`，`Ω0=2669`，`ħc=197.3`，`ℓP=1.616e-35` | **1.00123** | +0.123% | **进钉死** |
| **对照 0.99961** | 精确 `m0=mτ/q⁴`（`q=e^(−S1)`）→ ≈6230.82，`Ω0≈2671.1`；CODATA `ħc`、`ℓP` | **0.999610** | −0.039% | **不进钉死** |
| 旧中间取位 | 先取位再乘 | ~0.9998 | — | **不采用** |
| 事件比（非 G 钉死） | 分母换 `4 ln 2` | 1.0585 | +5.85% | 锁纠缠，不改 G |

钉死相对对照约 **0.162%**，是字典差，不是第二套公式。

### 不要当成「算错」的几笔

| 项目 | 说明 |
|:---|:---|
| 事件锁 vs 几何锁 | `4 ln 2` 对 `16π cκ`，约 **5.7%**；两套分母不许并 |
| `G/Gobs ≈ 1.0012` | 未圆整全链几何钉死 |
| 对照 `0.99961` | 精确 `m0` + CODATA；不许说成「更正确的 G」 |
| 旧印数 `0.9998` | 中间取位叠出；不采用 |
| `ℏ` 的 SI 打印数 | 字典循环，不是预言靶 |
