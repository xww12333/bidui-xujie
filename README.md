# 《比对续接——差异传态网络》

正文：`卷1.md`–`卷17.md`。`scripts/` 只复算印数，**不能代替推导**。

---

## 简要概述

本项目从一个追问出发：**差异存在为什么存在？**  
追问下来会发现：所谓「差异存在」，并不是另立的一条公理，而是**不可约比对操作持续续接作用**这一活动本身所呈现的**面向**——比对只与近邻作用，结果立刻成为下一步的作用对象；活动在，差异就在。

对这条活动做**面向的代数分析**：面向如何自交互、如何轮替、乘积如何闭合。数完面向，恰好三个；把这些硬约束记下来，记录语言就是**四元数 ℍ**（代数是记录，不是事先选好的舞台）。

再看活动的**近邻作用**如何在续接里铺开：三个面向长成三根锁死的管，比对沿管延续叫做**传态**；事件与螺旋是同一句话的两读。于是得到一张**传态网络**——一边用 **ℍ 代数**记账，一边用**三管螺旋、正交、协变的动态几何**描述同一过程；两者共同刻画这张网，不是两套无关的故事。

其后出现的谱、耦合、时空、G 与 ℏ 等，**不是外贴参数表**。它们来自对这张传态网络上**局域事件**（交汇、翻转、绕面、堆积、截面……）的结构分析：座位定在哪一层、哪一口，数就从那里读出。实验能量切口实质上只有一刀（`mτ`）；其余大量关系是网络内的无量纲结构。认知篇则表明：同一套生成条件还可读另一张图，但**不与物理网共享顶点**。

一句话：**追问差异 → 看见比对续接的面向 → ℍ 记录三面向闭合 → 近邻传态长成代数与三管几何共写的网络 → 一切可钉死的数，都是这张网上局域事件的分析结果。**

## 先看这五条（关键点）

1. **方向不可倒**  
   不是先选 ℍ / 标准模型 / Einstein，再给差异找舞台。  
   比对近邻续接自己提出要求 → 记成代数 → 记录名才叫 ℍ。

2. **差异存在不是公理表第一条**  
   它不能被证明、也不能被否定；启用证明已经在用它。  
   本项目的「证明」= 沿规划路径重演比对，看**打不打结**（断在哪）。

3. **实验能量切口只有一刀：`mτ`**  
   其余大量无量纲结构（`nk`、`S1`、`q`、`40`、`3/13`、堆积…）从座位长出，不是一堆自由拟合旋钮。

4. **两口不并、座位分明**（全文最高频禁令）  
   尤其卷16：**几何锁 G**（分母 `16π cκ`）与 **事件锁 ℏ**（每边 `ln 2`）交叉在同一根 `a_UV`，**不许并成一个分母**。  
   把事件比 ~1.058 说成「G 算错」，或把对照 `0.99961` 收进钉死，都断。

5. **三个「三」不可互换**  
   三面向（卷1）≠ 空间三维（卷14）≠ 三代/三色（后文各有座位）。并成一句就会读歪整条链。

## 三条纪律（怎么读、怎么改）

| 纪律 | 意思 |
|:---|:---|
| **不假装做了的** | 没推到的不写进钉死；读法 / 对照 / 字典循环要标清 |
| **两口不并** | 事件前与事件后、几何与事件、两口井、两张图……座位分开 |
| **座位分明** | 同一个数（如 `40`、`1/√2`、`ln 2`）出现多次，角色不同，禁止抄席 |

每卷开头有「本卷要解决什么」；关键推导后有「断在哪」。打结处就是禁跳点。

## 重点关节点（比目录更重要）

### A. 卷1：为何恰好三个面向

续接要求记下之后数面向：1 个方向消失；2 个乘积关不住；**3 个乘法表闭合 = ℍ**；≥4 无处转向。  
停在 ℍ。管、粒子、时空下一卷才开始。

### B. 卷2–3：网络与账本

三个面向 → 三管锁死 → 传态（比对沿管延续）→ 绕最小面 `H_P=−1`。  
同一笔传态分三层账 → 规范群是账本自同构，不是外加装饰。

### C. 卷4→5：公共尺 + 唯一切口

| 符号 | 来路 | 后文干什么 |
|:---|:---|:---|
| `nk = 4,13,30` | 交汇/翻转计数 | 轻子指数等 |
| `S1 ≈ 0.31367` | 交汇 BPS 鞍点 | `q`、`α`、ℏ 分母… |
| `q = e^(−S1)` | 由 `S1` | 质量比 |
| `m0 = mτ/q⁴` | **唯一**实验能量切口 | `Ω0`、`vH`、谱锚 |
| `40 = 1+3+9+27` | 取向完备和 | **只**进 `vH=40 m0` 等指定席；禁止抄进每一代轻子/夸克比 |

### D. 卷12：精细结构怎么到 137

不是 `S1` 直接等于 137。必须走**三刀**：

1. `40π/(3 S1) → 1/α(Ω0) ≈ 133.543`  
2. 方案差 ≈ 0.621（不进 β 对数）  
3. 硬阶跃 − **只扣一次** `ln 4` → 合成 `1/α(0) ≈ 137.029`  

Weinberg：`sin²θW = 3/13`（`13=1+3+9`），**禁止把 `Nw=2` 写进 13**。

### E. 卷16：G 与 ℏ（全文最要钉死的分家）

| 锁 | 锁什么 | 分母/机制 | 钉死数字 |
|:---|:---|:---|:---|
| **几何** | G | `16π cκ`（事件后） | `G/Gobs ≈ 1.0012` |
| **事件** | ℏ 与纠缠 | 每边 `ln 2`（事件前） | 形式站住；**SI 数值不是合法靶** |
| 交叉点 | 同一根 `a_UV` | `a_UV = L_IR / 40^12` | 两锁相遇处，不是并句处 |

对照 `0.99961` = 精确 `m0` + CODATA 字典，**同公式、换输入**，不进钉死。  
旧中间取位 `0.9998` **不采用**。

### F. 卷17：认知

认知 = 路径序被局域维持着重演。  
与物理图**共享生成条件，不共享顶点**；不回头改谱、G、ℏ。
